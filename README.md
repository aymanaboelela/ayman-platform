# منصة م. أيمن أبو العلا

منصة تعليمية عربية لطلاب **البرمجة وعلوم الحاسب** في نظام **البكالوريا المصرية** — كورسات ومشغّل دروس ومحرك اختبارات ولوحة تحكم كاملة، عربي RTL من الأساس.

---

## التشغيل محليًا

**المتطلبات:** Node 24+ · pnpm 11 · PostgreSQL 16 · Redis 7

```bash
pnpm install

# إنشاء الداتابيز والأدوار الثلاثة (مرة واحدة بس)
psql -d postgres -f scripts/db-bootstrap.sql

# ملفين بيئة، مش واحد — الجذر فيه الداتابيز والريديس، وبتاع الـ API
# فيه كمان أسرار الأوث وإعدادات الميديا. عدّل الباسوردات لو غيّرتها في السكريبت.
cp .env.example .env
cp apps/api/.env.example apps/api/.env

pnpm --filter @ayman/api exec prisma migrate deploy
pnpm --filter @ayman/api exec prisma generate
pnpm db:seed

pnpm dev
```

| الخدمة | البورت |
|---|---|
| الويب (Next.js) | `3200` |
| الـ API (NestJS) | `3300` |

> الـ API لازم يكون شغّال عشان الويب يفتح — الليّاوت الرئيسي بيقرأ إعدادات البراند منه.

## قرارات معمارية أساسية

**أصل واحد (Single origin).** الويب على `/` والـ API على `/api` ورا نفس الأصل. ده قرار أمني مش راحة — بيخلي `__Host-` cookies و`SameSite=Strict` ممكنين، و**مفيش CORS خالص** في أي مكان.

**صلاحيات أقل ما يمكن في الداتابيز.** تلات أدوار: `ayman_owner` (الميجريشن بس)، `ayman_runtime` (قراءة وكتابة بس، **مفيش DDL**)، `ayman_readonly`. يعني لو حصل SQL injection مش هيقدر يعمل `CREATE FUNCTION` ولا `DROP TABLE`.

**RTL أصلي مش مقلوب.** في ESLint rule بترفض `ml-*` و`left-*` وأخواتهم، وبتشوف جوه `cn()` و`clsx()` والـ ternaries.

**كل النصوص في مكان واحد.** مفيش أي نص عربي مكتوب جوه المكوّنات — كله في `packages/contracts`. عشان إضافة الإنجليزي بعدين تبقى تغيير في الراوتنج مش إعادة كتابة.

**الصور ورا بوابة واحدة.** كل صور السطح التسويقي بتعدّي على `<MediaSlot>` وبتتقرا من `apps/web/lib/brand-assets.ts`. من غير صورة مسجّلة بيرسم بديل مصمّم بنفس المقاسات — يعني تركيب صور جديدة تعديل في ملف واحد، من غير ما اللياوت يتلمس.

## السطح التسويقي

اللاندنج تسع سكاشن، حركتها كلها **GSAP + ScrollTrigger** فوق **Lenis** للسكرول الناعم:

- **الهيرو** — صورة بالعرض الكامل، عنوان بيتبدّل بين صيغ، وشريط إحصائيات
- **ليه تتعلم هنا** — السكشن بيتثبّت والكروت بتمشي أفقي مع السكرول
- **الكورسات المميزة** · **اختر صفّك** (كروت على شكل محرر كود) · **المختبر التفاعلي** (تشغيل JS في Web Worker معزول) · **عن المدرّس** · **الأسئلة الشائعة** · **الفوتر**
- **التنين** — ماسكوت ثابت في الشاشة بينزل مع القارئ على طول الصفحة

كل حركة مستمرة بتقف تحت `prefers-reduced-motion`، وكل تأثير مربوط بالماوس بيتقفل على الشاشات اللمس.

المكوّنات المستوردة من [React Bits](https://reactbits.dev) موجودة في `apps/web/components/site/vendor/` ومعاها [README](apps/web/components/site/vendor/README.md) بيوثّق كل تعديل اتعمل عليها وليه — عشان تحديثها بعدين ما يضيّعش الشغل.

## نظام البكالوريا

| النظام | المجموع | النجاح | التحسين |
|---|---|---|---|
| البكالوريا المصرية | 600 | 70% | لحد 4 مرات |
| الثانوية العامة | 320 | 50% | لأ |

النظامين **بيشتغلوا مع بعض**، البكالوريا مش بديل. أول امتحان بكالوريا **يونيو 2027** — يعني مفيش طلبة صف تالت بكالوريا لحد 2027/2028، والصف التاني لوحده **67%** من المجموع.

المسارات الأربعة: الطب وعلوم الحياة · الهندسة وعلوم الحاسب · الأعمال · الآداب والفنون.

## إمكانية الوصول

`apps/web/e2e/a11y.e2e.ts` بيشغّل axe على كل صفحة عامة، على الديسكتوب والموبايل، وبيرفض أي مخالفة `serious` أو `critical`. قايمة الصفحات **بتتحدّث بالإيد** — أي راوت عام مش مضاف فيها هو بالظبط اللي هيقع من غير ما حد ياخد باله.

الفحص بيشتغل تحت `prefers-reduced-motion` عشان يقيس الصفحة **وهي مستقرة** مش وهي في نص أنيميشن الدخول.
